# FLYINBIRD // AI & Robotics Workshop Systems

An ultra-premium, brutalist yet refined 2D minimalist B2B landing page inspired by the **"Nothing" brand aesthetic**, engineered with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

---

## 🖤 Design System: The "Nothing" Aesthetic

- **Color Palette**:
  - `bg-black`: Deep pitch black canvas.
  - `text-stone-100`: Swan / cream white primary typography.
  - `border-white/10`: Dark charcoal 1px grid lines and blueprint borders.
  - `text-amber-200`: Subtle light gold strictly reserved for micro-accents, terminal indicators, and active states.
- **Typography**:
  - Primary Display: **Space Grotesk** & **Inter** (clean geometric sans-serif).
  - Technical Overlines & Specs: **JetBrains Mono** (engineering dot-matrix feel).
- **Layout**: Strict 1px modular grid borders, sharp corners (`rounded-none`), and massive negative space.
- **Zero 3D Engine Overhead**: Instant loading, 306 kB lightweight bundle, 60fps on all school hardware and Chromebooks.
